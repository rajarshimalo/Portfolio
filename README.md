# Rajarshi Malo - Data Analytics Portfolio

A premium, interactive portfolio website showcasing data analytics, data science, and AI/ML skills.

## Tech Stack

- **React 18** with TypeScript
- **Vite** for fast development
- **Tailwind CSS** for styling
- **Framer Motion** for animations
- **Recharts** for data visualizations
- **Lucide React** for icons

## Features

- 🎨 **Interactive Hero** with particle animations
- 📊 **Analytics Lab** - Live data filtering and visualization
- 🛠️ **Skills Ecosystem** - Interactive skill cards with mini charts
- 📈 **Data Workflow** - Animated pipeline visualization
- 🎯 **Learning Journey** - Scroll-triggered timeline
- 📱 **Fully Responsive** - Optimized for all devices
- ♿ **Accessible** - Keyboard navigation and reduced motion support

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view it in the browser.

### Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## Project Structure

```
src/
├── components/       # Reusable UI components
├── sections/         # Page sections (Hero, About, Skills, etc.)
├── data/            # Sample datasets and portfolio data
├── hooks/           # Custom React hooks
├── App.tsx          # Main app component
├── main.tsx         # Entry point
└── index.css        # Global styles
```

## Performance

- Optimized animations for 60 FPS
- Lazy-loaded components
- Respects `prefers-reduced-motion`
- Efficient chart rendering
